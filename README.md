# Capybara Café

This project is a personal frontend practice aimed at improving my skills as a web developer.

I am building a café website using **React** and **Tailwind CSS**, focusing on clean UI, responsive design, and smooth user experience.

- Modern and responsive design
- Smooth navigation and scrolling
- Styled with Tailwind CSS
- Built with React components

- HTML5 & CSS3
